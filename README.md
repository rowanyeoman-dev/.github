# rowanyeoman-dev

This repository holds the agent plugin marketplace for the Social Lean Canvas fleet.

Add it once at claude.ai, Customize, Plugins, Add, Add marketplace: `rowanyeoman-dev/.github`. It lists four plugins:

| Plugin | Source | What it gives an agent |
|---|---|---|
| `slc` | this repository | Owner rules, the issue form, the owner hand-off format |
| `polar` | `polarsource/agent-toolkit` | Polar's MCP servers (`polar`, `polar-sandbox`) and skills |
| `better-auth` | `better-auth/skills` | Better Auth's skills and documentation MCP server |
| `cloudflare` | `cloudflare/skills` | Cloudflare's skills and API MCP server |
